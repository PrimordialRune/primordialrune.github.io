## Project Overview

Portfolio website for **Omar Golinelli (PrimordialRune)** showcasing Game Design and Game Development projects. Built with Next.js 16, TypeScript, Tailwind CSS v4, and Framer Motion. Uses static export for GitHub Pages deployment.

**Design Direction:** Mix of retro (NES/Gameboy era) and modern/minimal aesthetics with emphasis on 2D animations.

## Commands

```bash
npm run dev      # Start development server (http://localhost:3000)
npm run build    # Build static export to ./out
npm run lint     # Run ESLint
```

## Framer Motion

Animation library for React. Key patterns used in this project:

```tsx
"use client"; // Required for Framer Motion components

import { motion, AnimatePresence } from "framer-motion";

// Morphing navigation with layoutId (shared element transition)
<motion.button
  layoutId={`nav-item-${item.id}`}
  animate={{ paddingLeft: navOpen ? "420px" : "0px" }}
  transition={{
    type: "spring",
    damping: 25,
    stiffness: 250,
    mass: 0.8,
  }}
/>

// Pulsing animation (scanlines)
<motion.div
  animate={{
    opacity: [0.7, 1, 0.7],
    scaleX: [1, 1.05, 1],
  }}
  transition={{
    opacity: { duration: 2, repeat: Infinity, delay: index * 0.2 },
    scaleX: { duration: 2, repeat: Infinity, delay: index * 0.2 },
  }}
/>

// Conditional entrance animation (nav content)
<AnimatePresence>
  {isOpen && (
    <motion.div
      initial={{ opacity: 0, y: 10 }}
      animate={{ opacity: 1, y: 0 }}
      exit={{ opacity: 0 }}
      transition={{ delay: 0.15 }}
    />
  )}
</AnimatePresence>

// Spring-based scale animation
<motion.div
  initial={{ scale: 0 }}
  animate={{ scale: 1 }}
  transition={{
    type: "spring",
    damping: 20,
    stiffness: 300,
    delay: 0.1,
  }}
/>
```

**Critical Pattern:** For morphing UI elements that should stop animating when state changes, use **conditional rendering** (`{!isOpen && <motion.div />}`) instead of `<AnimatePresence>` to ensure animations fully terminate.

Components using Framer Motion must be client components (`"use client"` directive).

## Phase 1 Implementation Details

### Morphing Navigation Mechanics

The navigation uses a **single object transformation** approach where scanlines morph into full navigation items. Critical implementation details:

#### Positioning & Spacing
```tsx
// Navigation container (Navigation.tsx)
position: fixed
top: 6.5rem      // Aligns below header with proper spacing
bottom: 2rem     // Leaves space for bottom stripe
left: 2.5rem     // Positioned in left margin
z-index: 50

// Main content area (page.tsx)
padding-top: 5.5rem    // Clears header
padding-bottom: 8px
padding-x: 6px
```

#### Scanline → Nav Item Transformation
```tsx
// Each nav item has TWO visual states, NOT separate components:
width: "400px"  // Same width in both closed and open states
flex: isOpen ? (isActive ? "2" : "1") : "0 0 15px"
border-radius: isOpen ? "rounded-2xl" : "rounded-full"

// CRITICAL: Scanline animation MUST stop when morphed
{!isOpen && (
  <motion.div
    animate={{
      opacity: [0.7, 1, 0.7],
      scaleX: [1, 1.05, 1],
    }}
    transition={{
      opacity: { duration: 2, repeat: Infinity, delay: index * 0.2 },
      scaleX: { duration: 2, repeat: Infinity, delay: index * 0.2 },
    }}
  />
)}
// Do NOT use AnimatePresence here - it causes animation persistence
```

#### Spring Physics Parameters
These values create the "Persona 5 snappy" feel:
```tsx
transition={{
  type: "spring",
  damping: 25,      // Controls bounce (higher = less bounce)
  stiffness: 250,   // Speed of animation (higher = faster)
  mass: 0.8,        // Weight feel (lower = lighter, more responsive)
}}
```

#### Keyboard Navigation
```tsx
// Arrow Up/Down: Navigate between items
// Enter/Space: Select item
// Escape: Close navigation

useEffect(() => {
  const handleKeyDown = (e: KeyboardEvent) => {
    if (e.key === "Escape" && isOpen) {
      toggleNav(false);
      return;
    }

    if (!isOpen) return;  // Only navigate when open

    const currentIndex = navItems.findIndex(item => item.id === activeId);

    switch (e.key) {
      case "ArrowUp":
        e.preventDefault();
        if (currentIndex > 0) setActiveId(navItems[currentIndex - 1].id);
        break;
      case "ArrowDown":
        e.preventDefault();
        if (currentIndex < navItems.length - 1) setActiveId(navItems[currentIndex + 1].id);
        break;
    }
  };
}, [isOpen, activeId]);
```

### Critical Lessons Learned

1. **Animation Persistence Bug:** When morphing UI elements, use conditional rendering `{!isOpen && (...)}` instead of `<AnimatePresence>` to ensure animations fully stop when state changes.

2. **Morphing Width Consistency:** For seamless morphing, keep width constant (`400px`) and only change `flex` values and `border-radius`.

3. **Opacity Layering:** Use `/40` opacity for inactive states to create depth without losing visual hierarchy. Blood orange at 40% opacity still reads as orange but feels recessed.

4. **Flex-Based Expansion:** Active items get `flex: 2`, inactive get `flex: 1`, closed get `flex: 0 0 15px`. This creates natural vertical expansion without fixed heights.

5. **Parent-Child State Sync:** Use callback props (`onOpenChange`) to sync navigation state with parent component for coordinated animations.

6. **Spacing Rhythm:** Top spacing (6.5rem) > bottom spacing (2rem) creates visual balance. Left margin (2.5rem) gives navigation breathing room.

## Phase 2 Implementation Details

### FloatingProjects Component

Physics-based floating project cards with drag-and-drop functionality.

**Layout Algorithm:**
- Grid-based spawning with seeded random offsets for variety
- Card sizes based on importance (1-5 scale): Small (0.7x), Medium (1.0x), Large (1.3x)
- Fills 40-70% of container with optimal aspect ratio

**Drag & Drop:**
```tsx
// Long press (300ms) enables drag
onPointerDown={() => handlePointerDown(index)}

// Version-based key forces clean re-render after drag
key={`${project.slug}-v${version}`}

// dragMomentum={false} prevents bounce after release
drag={isBeingDragged}
dragMomentum={false}
dragConstraints={containerRef}
```

**Collision Resolution:**
- Golden angle distribution for deterministic push direction
- 1.2x card width minimum distance between projects

### ProjectModal Component

Modal with 3D tilt effect and two color modes.

**3D Tilt Effect:**
```tsx
// Track mouse position relative to modal
const handleMouseMove = (e: React.MouseEvent<HTMLDivElement>) => {
  const rect = modalRef.current.getBoundingClientRect();
  const x = (e.clientX - rect.left) / rect.width;
  const y = (e.clientY - rect.top) / rect.height;
  setMousePosition({ x, y });
};

// Calculate tilt (±8° rotation)
const tiltX = isHovered ? (mousePosition.y - 0.5) * -8 : 0;
const tiltY = isHovered ? (mousePosition.x - 0.5) * 8 : 0;

// Apply to motion.div
animate={{ rotateX: tiltX, rotateY: tiltY }}
style={{ transformStyle: "preserve-3d", perspective: "1000px" }}
```

### Seeded Random Utility

Deterministic randomness for consistent layouts across renders.

```tsx
// lib/utils.ts
export function seededRandom(seed: number): number {
  const x = Math.sin(seed) * 10000;
  return x - Math.floor(x);
}

// Usage with golden angle for distribution
```
