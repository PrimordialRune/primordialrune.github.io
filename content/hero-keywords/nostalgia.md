# Nostalgia / Retrogame

## Fun Facts

- Retro aesthetics evoke emotional connections beyond mere graphics
- Pixel art is a deliberate artistic choice, not a limitation
- Chiptune music creates unique soundscapes through constraints
- The "NES hard" difficulty created a generation of persistent gamers
- Retro revival games blend old aesthetics with modern game design lessons

## Random Facts Pool

- The Game Boy's green screen became iconic through limitation
- CRT scanlines were never meant to be visible - now they're nostalgic
- Password systems before save files created shared gaming moments
- Arcade game design optimized for "one more quarter" psychology
- Sprite limitations forced creative visual storytelling
