# Dialogue System UI - Case Study

## Project Brief

Create a dialogue system that supports:
- Character portraits and emotions
- Player choice branches
- Text effects (typewriter, shake, color)
- Auto-advance and skip options

## Design Process

Started with research into visual novel conventions and JRPG dialogue boxes. Iterated on readability, timing, and visual clarity.
