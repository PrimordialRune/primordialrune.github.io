## Overview

An educational tool for visualizing pathfinding algorithms in real-time, helping users understand how different algorithms explore and find optimal paths.

## Algorithms Included

### A* (A-Star)
- Combines path cost with heuristic
- Optimal with admissible heuristic
- Most efficient for most cases

### Dijkstra's Algorithm
- Guarantees shortest path
- Explores uniformly in all directions
- Good baseline comparison

### Breadth-First Search
- Unweighted graph traversal
- Finds shortest path by edges
- Useful for equal-cost movement

### Depth-First Search
- Memory efficient
- Not optimal for pathfinding
- Educational comparison

## Features

### Interactive Grid
- Click to place walls
- Drag to draw obstacles
- Move start/end points
- Adjustable grid size

### Visualization Controls
- Step-by-step mode
- Adjustable speed
- Color-coded states
- Path reconstruction display

### Heuristic Options
- Manhattan distance
- Euclidean distance
- Diagonal distance
- Custom heuristics

## Educational Value

This tool helps students and developers understand the trade-offs between different pathfinding approaches and how heuristics affect algorithm behavior.
