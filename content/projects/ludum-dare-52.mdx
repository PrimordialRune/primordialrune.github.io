## Overview

Harvest Rush was created in 48 hours for Ludum Dare 52, a global game jam with the theme "Harvest". The game challenges players to collect crops against the clock while managing limited inventory space.

## Game Design

### Core Loop
- Plants spawn randomly across the field
- Players must harvest before time expires
- Each crop type has different point values
- Inventory management adds strategic depth

### Mechanics
- Time pressure creates urgency
- Combo system rewards efficient harvesting
- Power-ups provide temporary boosts
- Multiple crop rarities encourage exploration

## Technical Implementation

Built quickly using Unity's 2D tools with:
- Scriptable Objects for crop data
- Object pooling for performance
- Simple state machine for game flow

## Post-Mortem

### What Went Well
- Scope stayed manageable
- Core loop was fun immediately
- Art style was cohesive

### Lessons Learned
- Need more playtesting time
- Audio adds more than expected
- Polish matters even in jams
