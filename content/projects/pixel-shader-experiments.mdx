## Overview

A technical sandbox for exploring CRT effects, dithering patterns, color quantization, and other retro visual styles common in classic video games.

## Shader Collection

### CRT Effects
- Scanline rendering
- Screen curvature
- Phosphor glow
- RGB subpixel simulation

### Color Processing
- Palette quantization (NES, Game Boy, CGA)
- Ordered dithering patterns
- Error diffusion dithering
- Color grading curves

### Distortion Effects
- Chromatic aberration
- Barrel distortion
- VHS tracking artifacts
- Signal noise

## Technical Implementation

### Shader Structure
- Modular post-processing stack
- Per-effect enable/disable
- Real-time parameter tweaking
- Performance profiling

### Optimizations
- Single-pass combinations
- LUT-based color operations
- Resolution-independent effects

- Retro game aesthetic
- Stylized presentations
